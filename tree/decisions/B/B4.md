## Decision

Every call that is async upstream (editor mutations, signal emits, pipes, node data, engine fetches) returns a Rust future. Ruggine ships no executor and needs none: any executor can drive the futures, and a graph whose pipes and nodes are all synchronous finishes on the first poll. Futures are single-threaded (not Send), like JavaScript.

## Why

Solenoid has nodes whose data is genuinely async (frames, scripts, live connections, composites) and relies on reset cancelling a fetch in flight, so a sync port couldn't replace rete there.
