## Decision

NodeEditor, Scope, Dataflow and the engines are handles over shared state, so a pipe or an engine can hold one. Nodes and connections are stored as Rc and the editor hands out clones of the same Rc, so identity works like upstream's shared objects. The classic preset keeps what upstream mutates after creation (labels, sockets, ports, controls, selection) behind interior mutability. A child scope holds its parent weakly, so editor and engine don't keep each other alive.

## Why

Upstream code mutates nodes after adding them and lets plugins reach the editor, and Solenoid depends on both, so the port has to allow shared, mutable objects.
