## Decision

Both crates compile for wasm32-unknown-unknown and for native targets, and CI checks both. No dependency that needs threads, an OS or a JS runtime.

## Why

Solenoid's Rust core runs as wasm on the web and natively on desktop, so whatever it builds on has to do both.
