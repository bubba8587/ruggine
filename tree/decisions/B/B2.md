## Decision

Both crates compile for wasm32-unknown-unknown and for native targets, and CI checks both. No dependency that needs threads or an OS. On wasm the one call out to the host is randomness for ids, through getrandom's browser backend ([[B9]] randomIds).

## Why

Solenoid's Rust core runs as wasm on the web and natively on desktop, so whatever it builds on has to do both.
