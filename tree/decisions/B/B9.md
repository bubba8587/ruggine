## Decision

getUID returns 8 random bytes as 16 lowercase hex characters. The bytes come from the platform's secure random source (getrandom, through the browser's crypto on wasm), and a test or a host can swap the source for its own.

## Why

Ids end up in Solenoid's saves and get pasted between documents, so they must keep upstream's shape and stay unique across sessions; upstream's own tests mock the random source, so the port needs the same seam.
