## Decision

Until Solenoid ships on Ruggine, any API can change in one clean step; Solenoid's call sites are updated in the same change instead of keeping the old shape alive.

## Why

Solenoid is the only user, so compatibility layers would only slow the port down. Solenoid holds the same rule for itself.
