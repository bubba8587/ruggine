## Decision

Ruggine does what rete and rete-engine do: the same graph changes, the same events in the same order, the same calculated values, the same errors. Where Ruggine can't or shouldn't match (a case where rete itself breaks, or one JavaScript allows and Rust can't express), the difference and its reason are written down in the port spec, and nowhere else may Ruggine differ.

## Why

Solenoid already runs on rete, so anything Ruggine answers differently is a change in Solenoid that nobody chose.
