## Decision

The pinned upstream source in upstream/ is the reference for every behavior. A module is ported by first translating its upstream tests into Rust tests, then writing the code until they pass. Where Rust can't express an upstream behavior the same way, the difference is written down as a decision.

## Why

A port is only as good as its match to the original, and upstream already wrote down what it does in its tests.
