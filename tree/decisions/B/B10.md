## Decision

Ruggine is a Rust library. Solenoid reaches it by moving its graph layer into its Rust core, as it moves everything but the React UI; there is no npm package with rete's API.

## Why

The point of the Solenoid port is to bring everything reasonable into Rust, and rete was an outside library, so it got its own repo as an independent Rust library rather than a JS replacement.
